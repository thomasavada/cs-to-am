## Six boxes

Every merchant message is about **one box**:

```
GET PEOPLE IN     →  ads / email / they remember the name
ON THE SITE       →  homepage, product, cart, popup
PAY               →  checkout, discount, shipping
AFTER THE ORDER   →  email, “where is my order?”, refund
COME BACK         →  refill, next drop, membership, subscription
MONEY             →  first order cost them; second order is the win
```

Loyalty lives in **COME BACK**. They do not need Joy to decode the message. They need the boxes.

---

## Three numbers (only math)

1. **Orders** — how many times people paid
2. **Typical basket** — how fat one order is
3. **Came back** — of 100 buyers, how many bought a second time

A shop that only gets first-time buyers is usually dying, even if something is “set up.”

---

## Two owner fears

1. I keep buying new people who vanish.
2. I keep making this order cheaper for people who would have paid anyway.

## Word → box (not ESL)

| They hear | Box |
|---|---|
| product page / PDP / listing | ON THE SITE |
| cart / checkout / shipping threshold | ON THE SITE / PAY |
| popup / opt-in | ON THE SITE (getting the email) |
| fulfillment / tracking / refund | AFTER THE ORDER |
| Klaviyo / flow / campaign | GET PEOPLE IN or AFTER / COME BACK |
| repeat / retention / VIP / points / redeem | COME BACK |
| ROAS / CAC / “spending too much on ads” | GET PEOPLE IN + MONEY |
| conversion is down | ON THE SITE → PAY (they came, they didn’t buy) |

| Word they freeze on | Means |
|---|---|
| conversion / CVR | people came to the site, didn’t buy |
| AOV / basket / order value | how fat one order is |
| traffic | people arriving (usually ads) |
| returning / repeat / retention | second (or 5th) order |
| churn | they stopped coming |
| CAC | what it cost to get a new person |
| discount / code / sitewide | this order is cheaper — fear 2 |
| popup | grabbing email; can also annoy and kill the sale |
| flow / campaign | automatic email vs a one-off blast |
| subscription / replenish / subscribe-and-save | next box is already agreed |
| VIP / tier / membership | best customers get something others don’t |
| redeem / redemption | they *used* the reward, not only earned it |
| stack | two discounts on one order |
| wholesale / B2B | not the normal shopper |
| drop / restock / launch | new product moment — come-back for apparel |
| attribution | which channel gets credit — they don’t need to solve this |

**Subscription ≠ loyalty ≠ discount**  
Standing order / reason to choose you next time / this order is cheaper.

## Banned vs allowed

**Banned:** “Could you please provide more details?” / “Can you explain more?”  
That is how they hide. It makes the merchant write the ticket for them.

**Allowed:** one fork that proves they already understood 80%.

## Forward template

They may not forward if **I think** is empty.

```
Box:          (site / pay / after / come-back / money / get-in)
Fear:         (vanish / we over-discount / unclear)
They said:    (1 short quote)
I think:      (2 sentences, own words)
Still unsure: (one fork, or “none”)
```

## Four questions (any merchant, before any screen)

1. What does this shop sell?
2. Why would a person buy a second time?
3. What do they expect if they launch loyalty — more coming back / more earned?
4. How do we get them to that result faster?
