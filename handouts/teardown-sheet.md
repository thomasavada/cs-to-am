# Brand teardown — the one instrument

The whole course is this sheet, run again and again on real brands.  
Not theory. Not memorising. You **look at a real shop and say what it is doing.**

**Rule — outside-in:** if you cannot see it on the public website without a login, it is not on this sheet.  
No ad account. No Joy admin. No merchant interview. Just the site.

First time: ~45 min. By rep 4: ~15 min.

## 1. Money on one unit

Before ecom words. This is the Adidas question.

> An Adidas shoe sells for **$180**. It costs about **$25–30** to make. Adidas sells it to a shop for about **$90**. The shop sells it to you for $180. The outlet takes 40% off → **$108** — and it is *still* above what the shop paid.
>
> Price is not "cost plus a bit." It is **layers**, and each layer pays for something. A discount does not eat the profit — it eats the layer that pays for everything else.
>
> DTC skips the shop. That is why DTC exists. But then **they pay for traffic instead** — the ad is their new middleman. That is the whole game.

## 3. The path to paid

Walk it yourself as a customer. Do not read about it.

```
land  →  product page  →  add to cart  →  checkout
```

For each step write **one thing that makes you want to continue** and **one thing that would make you quit.**

- Free shipping threshold? At what number?
- Guest checkout, or forced account?
- How many clicks from landing to paying?

This is what "conversion" and "add to cart rate" actually mean. People came. Some quit. Where.

## 5. The second order

The box Joy lives in. Answer honestly — "no reason" is a valid and very common answer.

- **Why would a human buy this twice?** (runs out / new drop / wears out / gift again / no reason)
- **Roughly when?** (weeks)
- **What does the brand actually DO about it?**
  - [ ] Subscription
  - [ ] Email flows
  - [ ] Drops / restock
  - [ ] Bundle / refill
  - [ ] Account / points / VIP
  - [ ] Nothing

**Name it correctly — these are three different things:**

| | |
|---|---|
| **Subscription** | the next box is already agreed |
| **Loyalty** | a reason to choose *you* next time |
| **Discount** | this order is cheaper |

## 6. The stack

What is installed tells you what the owner is **trying to do**. No login needed.

**How to check:** right-click → View Page Source → Ctrl-F for:

```
klaviyo · attentive · postscript · recharge · appstle · skio · smile
yotpo · loyaltylion · rivo · growave · okendo · stamped · judge.me
gorgias · rebuy · subscribe
```

Also: the footer, the `/account` page, and try `/pages/rewards` — if it 404s, they have no loyalty.

| Job | App found | What it tells you |
|---|---|---|
| Email / SMS | | |
| Subscription | | |
| Reviews | | |
| **Loyalty** | | |
| Support | | |
| Upsell / bundle | | |

**One line — what is this owner spending money to fix?**

> **The stack is a confession.** Every app is money spent because the owner was worried about something.
> Klaviyo = "I can't reach my visitors." Rebuy = "my orders are too thin." Recharge = "they buy once."
> A loyalty app = "I have a base and nothing brings them back." Nothing at all = very early, or nobody is minding the shop.
>
> Answer key: `4-journey.md` → *The stack is a confession*.

**And the sharpest question:** is what they installed aimed at their **actual** leak?
A bundle app fixes stop 6. If they are bleeding at stop 11, they are fixing the wrong thing.

**The easiest win to recognise:** Recharge or Appstle **+** Klaviyo **+** no loyalty app.

## Pass bar for a teardown

A lead accepts it if you can answer, without re-opening the site:

1. What does this shop sell, and how does it make money on one order?
2. How do people arrive, and where do they quit?
3. Why would someone buy a second time — and what is the brand doing about it?
4. Is it ours, and what is the one thing we would change?
