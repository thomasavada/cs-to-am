Same journey, only the cash. This is the part to put on the board.

## Order 1

| | |
|---|---|
| Ad spend to reach Mai | **−$30.00** |
| Cart: moisturizer + travel size | +$68.00 |
| Popup 10% off | −$6.80 |
| She cleared the free-shipping threshold, so Lumi pays it | −$7.00 |
| Payment processing (~2.9% + 30¢) | −$2.07 |
| Cost of the actual products | −$20.00 |
| **What Lumi keeps** | **+$2.13** |

Mai spent **$61.20**. The shop kept **$2.13**.

Say that sentence in the room and stop talking for a second.

**Order 1 paid for the ad. That is all it did.**

## Order 2 — eight weeks later

| | |
|---|---|
| Ad spend | **$0.00** |
| Refill order | +$42.00 |
| Loyalty points redeemed | −$4.20 |
| Shipping | −$7.00 |
| Processing | −$1.52 |
| Product cost | −$12.00 |
| **What Lumi keeps** | **+$17.28** |

**One order with no ad attached is worth eight of the first one.**

Everything in this folder is downstream of those two tables:
- **Fear #1** — buying new people who vanish — is a shop that only ever books the first table.
- **Fear #2** — discounting people who would have paid — is the $6.80 and the $4.20, and whether they
  were spent on someone who needed convincing or someone who was already coming back.
- **Joy's entire job** is to make the second table happen, more often, sooner.
