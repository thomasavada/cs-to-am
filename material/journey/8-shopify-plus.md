# What changes on Shopify Plus

**Used in:** Session 2, aside

---


Worth knowing so they are not lost when a bigger merchant writes in:

- **Checkout is editable** — extensions, custom fields, checkout upsells, tiered logic
- **B2B / wholesale** on the same store
- **Multiple storefronts / markets** — different currencies, languages, price lists
- Higher API limits, launchpad for drops, dedicated support

Practical CS meaning: a Plus merchant asking about checkout is asking a **real** question. The same
question from a standard-plan merchant often has no answer, and saying so early saves everyone a week.
